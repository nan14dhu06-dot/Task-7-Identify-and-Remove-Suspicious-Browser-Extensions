Task 7: Identify and Remove Suspicious Browser Extensions

This repository contains my work for Task 7 of the Cyber Security Internship, which focuses on browser security, identifying risky extensions, and understanding how malicious add-ons can compromise user privacy and system safety.

📌 Objective
The main objective of this task is to detect suspicious browser extensions, analyze their permissions, evaluate their legitimacy, and safely remove any harmful or unnecessary add-ons. This task enhances awareness of browser security practices and teaches practical methods of maintaining a secure browsing environment.

🛠 Tools & Environment
Web browser: Google Chrome / Mozilla Firefox
Built-in extension/add-on manager
Internet search resources for verification
No third-party paid tools used

🔍 Task Procedure
1. Access Extension Manager
Opened the browser’s built-in extension/add-on management panel to view the complete list of installed extensions.
2. Review Installed Extensions
Carefully examined each installed extension to check:
Name & publisher
Purpose of the extension
Recent updates
User ratings and reviews
Number of downloads (if visible)
3. Check Permissions
Permissions were analyzed to identify red flags such as:
Ability to read/change data on all websites
Asking for unnecessary system-level access
Access to sensitive personal information
File system access (where applicable)

4. Identify Suspicious/Unused Extensions
Marked extensions that were:
Unused for a long time
Unknown or unrecognized
Installed accidentally
Showing unusual behaviour (pop-ups, redirects, ads)

5. Remove Harmful/Unnecessary Extensions
Safely removed all extensions found to be suspicious or no longer required.

6. Browser Restart & Verification
Restarted the browser to verify:
Performance improvements
Removal confirmation
Absence of unwanted ads/pop-ups

7. Research on Malicious Extensions
Studied how malicious extensions can:
Steal passwords and browsing data
Inject ads or redirect pages
Track user activity
Download malware
Bypass browser security

8. Documentation
Recorded all steps, findings, and removed extension details for internship submission.
🎯 Outcomes & Skills Gained
Through this task, I gained:
Awareness of browser extension security risks
Ability to spot suspicious permissions
Understanding of extension sandboxing
Knowledge of how malicious extensions exploit browsers
Practical skills in securing browser environments
